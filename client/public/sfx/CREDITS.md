# Sound credits

Every sound in this folder is cut from **CC0 1.0 (public domain)** recordings and packs.
No attribution is legally required, but these people made the game's sound possible —
thank you. The files are built by `tools/sfx/build.py`, which lists exactly which source
goes into which sound and how it was trimmed, filtered and mixed.
